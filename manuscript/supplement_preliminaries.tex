\section{Mathematical preliminaries}

\subsection{Finite operational systems}
A finite controlled ecological system is a tuple
\[
\mathcal{S}=(X,A,G,\delta,y),
\]
where $X$ is a finite state set, $A$ is a declared action alphabet, $G$ is the legal finite action grammar, $\delta$ is the controlled successor rule, and $y$ is the declared output. The grammar is part of the model: two states may be observationally identical yet operationally distinct if they admit different actions or different legal futures.

A macro-law is represented by a surjection $\pi:X\times G\to Q$. Its fibers are the ecological state classes supplied to prediction and intervention. Exactness requires equality of current output, legal-action rows, and successor macro-labels within every fiber. In the main text this property is interpreted as exact decision sufficiency for the declared target interface.

\subsection{Structural change and inherited target labels}
Let $\mathcal{S}_0$ and $\mathcal{S}_1$ be source and target systems. A declared total relation
\[
R\subseteq (X_0\times G_0)\times(X_1\times G_1)
\]
carries source labels to the target. When every target state is covered and each target fiber is source-label consistent, the induced carried classification is denoted $C=\pi_R$. The relation may be non-nested: turnover, replacement, or rewiring need not embed the source state space into the target.

The relation is part of the declared scientific model and is not inferred by the present framework. The audit asks whether the carried classification $C$ is exact for the target outputs and actions. If it is not, the admissible repair class consists of exact target partitions that refine $C$; this preserves inherited distinctions and only splits inherited classes where target operation requires it.

\subsection{Partition order and least exact distinction}
For partitions $P$ and $P'$ of the same finite set, write $P'\preceq P$ when every block of $P'$ is contained in a block of $P$. Thus $P'$ is a refinement of $P$. Let $Q^\ast$ denote the coarsest exact target partition among those refining $C$.

The existence and construction of such a coarsest stable refinement from a supplied initial partition are established partition-refinement results, as credited in the main manuscript. In this supplement, $Q^\ast$ is therefore treated as the specialized output of that standard construction, not as a newly invented generic mathematical object.

\subsection{Obstruction pairs and monitoring realization}
Define the obstruction-pair set
\[
E=\{(x,x'):C(x)=C(x'),\;Q^\ast(x)\ne Q^\ast(x')\}.
\]
Each pair records a distinction suppressed by the inherited classification but required by the exact target interface. If candidate measurements $z_j$ are available, a measurement set realizes the repair only when every pair in $E$ is separated by at least one selected $z_j$. This is the bridge from the formal audit to a targeted monitoring requirement.

\subsection{History-indexed transport}
For a rooted directed acyclic graph of declared structural changes, every root-to-terminal path induces a complete carried terminal map. Two paths are route-compatible for the inherited interface exactly when these maps agree. When they disagree, an immutable context indexes the distinct carried terminal maps before exact refinement is applied. This construction concerns externally declared replacement routes; it is not a claim that history-sensitive equivalence is new in general.
