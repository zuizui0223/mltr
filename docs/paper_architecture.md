# Paper A architecture — ecological decision-sufficiency audit

## One-sentence paper

An ecological state classification can remain interpretable after structural change while becoming insufficient for a new management action; Paper A audits that failure, identifies the least exact distinction that must be restored, translates it into a monitoring requirement, and determines when replacement-route history must remain explicit.

## Story arc

1. **Ecological practice starts from coarse states.** Managers use state-and-transition models, habitat classes, functional states, and other compressed interfaces because full ecological detail is not operationally manageable.
2. **Structural change can invalidate the interface.** Turnover, rewiring, habitat change, or a new intervention can expose differences that the inherited class suppresses.
3. **Audit before refitting.** Check outputs, legal actions, and action-conditioned successors within each inherited target class.
4. **Diagnose locally.** A pair of states and an action/future witness why the old state is no longer decision-sufficient.
5. **Repair only what is necessary.** Use established coarsest refinement to recover the least exact distinction while retaining every inherited merge still compatible with the target interface.
6. **Translate the split into monitoring.** Candidate measurements must separate the obstruction pairs generated by the repair.
7. **Keep consequences separate.** Structural defect, conditional information, monitoring cost, and decision regret answer different questions.
8. **Retain history only when it changes meaning.** Multiple declared replacement routes can share one interface only when they carry the same terminal label map.

## Main-text result hierarchy

### Result 1 — decision-sufficiency audit

Necessary and sufficient target-fiber conditions for unchanged reuse of the inherited state classification.

### Result 2 — local obstruction

A finite state pair and action/future identify the ecological distinction hidden by the inherited class.

### Result 3 — least exact distinction

Established Paige--Tarjan / Givan--Dean--Greig refinement machinery is instantiated at the carried classification. The construction is prior art; its role here is to return a canonical ecological repair target.

### Result 4 — consequences of repair

- structural state-count defect;
- conditional repair information when a target-state distribution is supplied;
- minimum monitoring realization over candidate measurements;
- decision regret as a separate utility-dependent quantity.

### Result 5 — route coherence / minimum context

Equality of complete terminal carried maps is the criterion for a route-independent inherited interface; otherwise one immutable context per distinct carried terminal map is necessary before exact refinement.

## Main ecological worked example

Plant--pollinator turnover:

- inherited class merges Sites A and B;
- a target competitor-removal action exposes different substitute-pollinator responses;
- the local witness identifies substitute-response capacity as the missing ecological distinction;
- least exact repair splits A and B;
- illustrative probabilities/costs show that the repaired classification can reverse restoration priority;
- the probability/cost values are sensitivity values, not empirical data.

## Discussion message

The key ecological message is not that managers should use a new aggregation algorithm. It is that **state validity is action- and objective-dependent**. A classification built for one structural and management regime can become insufficient under another. When it does, the correct response is to identify the specific hidden distinction that changes target action consequences, then redesign monitoring around that distinction rather than either keeping the old state blindly or rebuilding the entire ecological model from scratch.
